# Web Development Final Project

A small web development project using HTML, CSS, JavaScript, JSON data, and a simple Node.js server. The project presents timeline-style content with multiple pages and static assets.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- JSON

## Features

- Multi-page website structure
- Timeline page
- Static image assets
- JSON-backed data
- Basic Node.js server file

## How to Run

For the static pages, open `index.html` in a browser.

If you want to run the Node server:

```bash
node server.js
```

## What I Learned

- Structuring HTML/CSS pages
- Loading and organizing static assets
- Using JavaScript for page behavior
- Basic backend/server setup with Node.js
